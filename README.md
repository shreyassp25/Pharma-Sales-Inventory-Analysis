# Pharma Sales & Inventory Analysis 🧪

### Overview
This project analyzes pharmaceutical sales and inventory data using **Python, Pandas, and Matplotlib**.  
It identifies top-selling products, category performance, and low-stock items to support **restocking and pricing decisions**.

---

### 🧩 Dataset
A sample dataset was created to represent **one month** of sales data across multiple regions and product categories.  
Each record includes:
- Product ID & Name  
- Category (OTC, Antibiotic, etc.)  
- Units Sold (monthly)  
- Unit Price  
- Stock Remaining  
- Region  

---

### 📊 Key Analyses
- Total and category-wise sales performance  
- Regional revenue distribution  
- Low-stock and high-demand product detection  
- Profitability & restocking recommendations  

---

### ⚙️ Technologies Used
- Python  
- Pandas  
- Matplotlib  

---

### 💡 Insights Derived
- Identified top 3 revenue-driving medicines  
- Found products with low stock-to-sales ratio (restock alerts)  
- Discovered top-performing category and region  
- Suggested data-driven actions for pricing and supply optimization
